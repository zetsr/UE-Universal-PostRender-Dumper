## 使用方法 / Usage

### 确认配置 / Confirm Configuration
- 使用 [Dumper-7](https://github.com/Encryqed/Dumper-7) 生成SDK
- Generate the SDK using [Dumper-7](https://github.com/Encryqed/Dumper-7).
- 将 [Dumper-7](https://github.com/Encryqed/Dumper-7) 生成的 `CppSDK` 文件夹复制到 `UE-Universal-PostRender-Dumper\PostRenderDumper\SDK`
- Copy the `CppSDK` folder generated by [Dumper-7](https://github.com/Encryqed/Dumper-7) to `UE-Universal-PostRender-Dumper\PostRenderDumper\SDK`.
- 确认 `TARGET_WIDTH` 和 `TARGET_HEIGHT` 与你的游戏客户端一致
- Ensure that `TARGET_WIDTH` and `TARGET_HEIGHT` match your game client resolution.
- 确认 `SIZE_X_OFFSET` 与 `Dumper-7` 生成的 `SDK` 一致
- Verify that `SIZE_X_OFFSET` matches the SDK generated by `Dumper-7`.
- `生成解决方案`
- `Build Solution`

> 除非预设参数无法找到 `PostRender`，否则无需修改 `SCAN_RANGE` 与 `STABLE_FRAME_THRESHOLD`
> 
> There is no need to modify `SCAN_RANGE` and `STABLE_FRAME_THRESHOLD` unless the default parameters fail to find `PostRender`.

### 注入 / Injection
- 将生成的 `DLL` 注入到目标进程
- Inject the generated `DLL` into the target process.
- 检查控制台输出的信息，如果成功，屏幕左上角应该会出现 `Box`
- Check the console output information. If successful, a `Box` should appear in the top-left corner of the screen.
